## 🚀 Installation  

You can install `deeptransyt` in two ways:

### **1. Install via `pip`**
```bash
pip install deeptransyt
```

### **2. Cloning the repository**
If you want the latest development version:
```bash
git clone https://github.com/yourusername/deeptransyt.git
cd deeptransyt
pip install .
```
